- `Business_Studies_Answer_Bank/` — organised 4BS1 question-type inventory plus official Pearson student exemplars/examiner-report excerpts and a clearly labelled model-answer guide. See its README for sources and scope.

- `Paperlords_Archive/Selected_Test/` — one convenience copy of the Business Paper 1 used for the timed baseline; the original remains in the full archive.
