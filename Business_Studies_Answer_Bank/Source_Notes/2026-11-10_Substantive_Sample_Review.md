### Accuracy and marking cautions from this sample

- On Q1(d), accept only an IKEA-context reason; this is an application requirement, not just a definition of induction.
- On Q4(a), 13.95% is calculated relative to 2019 inventory (4.3). Using 3.7 as denominator would answer a different question. The printed task requests two decimal places.
- On Q2(c), the official mark scheme explicitly says a definition does not score and an unexplained list is limited. Avoid presenting a generic “three points” recipe as a universal rule; this is the criterion for this item.
- For Q3(d), the question-specific AO2/AO3 split and absence of knowledge marks are from this mark scheme/report, not a blanket statement about every analyse question.
- For Q3(e), the selected option needs reasons and evaluation; the 5/9 report commentary is direct evidence of what limited the candidate. No 9/9 candidate was checked in this sample.
- For Q4(c), the official 10/12 script is a near-full-mark example with limited judgements. The extracted OCR of the QP/MS can contain layout artifacts; refer to the retained PDFs for exact typography. The existing image-based transcription in `Perfect_Answers/02_Verified_Exemplars.md` is not newly re-transcribed here.

**Confirmed P2 content—not a contents-only identification:**

- **P2 Q1(a)(v), QP printed p.38 (page folio S56105A0416):** markup item asking for the selling price of an iPod nano 6 at 200% markup. It is P2. The markup denominator is cost; a 200% markup means profit is twice cost, so selling price is three times cost. P2 MS question label Q1(a)(v) is in the P2 MS section, pp.51–64.
- **P2 Q1(e), QP printed p.39 (folio S56105A0516):** gross-profit-margin calculation for an iPhone sold for US$800 with cost of sales US$200. Independently checked: gross profit US$600; margin = 600/800 ×100 = **75%**. This is a P2 calculation, distinct from the Haji Biriyani P1 figures. P2 MS question label Q1(e) is in the P2 MS section, pp.51–64.
- **P2 Q3(e), QP section pp.35–50:** justify funding Apple’s product development using either new shares or retained profits. The matching P2 MS Q3(e) assesses AO2/AO3/AO4 and its indicative material uses Apple’s 2015 profit of US$53.4bn as context for retained profit. Pearson’s *Getting Started Guide*, printed p.43 ([official PDF](https://qualifications.pearson.com/content/dam/pdf/International%20GCSE/Business%20Studies/2017/teaching-learning-materials/IG_Business_GettingStartedGuide.pdf)), also reproduces the P2 Q3(e) prompt and indicative guidance. This is a source-choice question, not proof that every source in §3.1 has an official example.

**Critical correction—P1 items previously mixed into the P2 SAM summary:**

- **P1 Q1(a)(v–vi), QP printed p.8** (the P1 section is printed pp.5–20; P1 MS begins p.21): closing cash balance **−200,000 Tks** and currency payment **15,500 Tks**. These are not P2 examples. Checked arithmetic: 1,200,000 + 1,400,000 − 2,800,000 = −200,000 Tks; 20 × 620 = 12,400 rupees and 12,400 ÷ 0.8 rupees/Tks = 15,500 Tks.

The P2 Q1(e) gross-margin item and Q3(e) finance-source item are verified anchors; other current clauses in the finance units are supported by other identity-matched papers or expressly constructed practice.
