# 09 — THE VERIFIED TALLY

**Derived, not asserted.** The bank previously carried hand-written totals — *"the bank now holds six 9/9s"* sitting directly above a list of fourteen, and a coverage table labelled *"6 × 9/9"* above a list of eight names. **Both were wrong.** A hand-written total is an assertion; a derived total is evidence.

Rebuild at any time:

```bash
cd Business_Studies_Answer_Bank
python3 tally_exemplars.py
```

The script reads every heading in every `.md` file in `Perfect_Answers/`, keeps those that claim a verified full mark **against a script**, applies any multiplier the heading states (*"two more"*, *"×3"*), and prints the file and line for each. **It asserts no number of its own.**

> ### 🚨 WHY THIS HAPPENED — and the rule that prevents it
> The counts were **hand-incremented** each time a new exemplar was found, while the lists beside them grew by transcription. **The two drifted.**
