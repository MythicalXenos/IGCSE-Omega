# Business Studies 4BS1 Answer Bank

Created 2026-10-12 from the Paperlords searchable archive and official Pearson materials.

## ⭐ Perfect Answers bank

`Perfect_Answers/` is the benchmark library of verified top-band answers for this subject — real student scripts reproduced by Pearson with the awarded mark printed alongside, plus the examiner's reasoning for every mark given and lost.

Start here:

- **`Perfect_Answers/01_Mark_Tariff_Playbook.md`** — the rules for every tariff (1/2/3/6/9/12), with AO splits, level bands and literal opening sentences.
- **`Perfect_Answers/02_Verified_Exemplars.md`** — the verified full-mark scripts, transcribed in full. Includes a **3/3**, **6/6** (×3), **9/9** and the archive's only **12/12**.
- **`Perfect_Answers/03_Calibration_Below_Full_Marks.md`** — near-miss scripts with the examiner's stated reason for every mark lost.
- **`Perfect_Answers/04_Type_Coverage_and_Gaps.md`** — the complete 696-item taxonomy and an honest statement of coverage limits.
- **`Perfect_Answers/Exemplar_Scans/`** — the genuine candidate scripts as page images.

Every answer in that folder is labelled `[VERIFIED CANDIDATE EXEMPLAR]` (official, score confirmed) or `[CONSTRUCTED GRADE 9 TARGET]` (engineered from the mark scheme, not official). No constructed answer is ever described as official.

## Deliverables

- `4BS1_Exemplar_and_Model_Answer_Guide.docx` — main reader-friendly guide: mark-format map, first-sentence starters, official student scripts/marker comments, and constructed full-credit targets where no full-mark script was located.
- `4BS1_Exemplar_and_Model_Answer_Guide.md` — searchable text master for the guide.
- `4BS1_Question_Type_Inventory.xlsx` — filterable workbook with (1) the curated question-family map, (2) detailed prompt-pattern map for each mark family, (3) item-level entries for every detected mark item in 38 archived QPs, including QP pages and matching QP/MS PDF paths, (4) official exemplar scores/pages and examiner takeaways, and (5) source register.
- `4BS1_Question_Instances.csv` — item-level question index in a portable/searchable format. Its PDF-path columns point into the full ZIP; for the paired extracted text, use the same relative path with `.pdf` replaced by `.txt` inside `Paperlords_Searchable_Text_Index.zip`.
- `build_question_inventory.py` — rebuilds the inventory from `Paperlords_Archive/Paperlords_Searchable_Text_Index.zip`.
- `make_docx.py` — rebuilds the DOCX from the Markdown guide.
- `Source_Notes/Official_Pearson_Exemplar_Index.md` — score-verified list of published scripts and exact source-page map.

## Source/marking policy

- “Official — full marks” means Pearson published the real candidate answer and score.
- “Official — not full marks” is still useful calibration and is labelled with the awarded mark.
- “Constructed full-credit target” means a new response written from the exact QP/MS/ER. It is not an official student answer and is not guaranteed a precise score.
- Mark schemes are primary for accepted content; examiner reports/exemplars help show how the criteria were applied. Do not treat one example as the only valid wording.

## Archive scope

The inventory was generated from 38 4BS1 QP text records in the searchable archive (P1/P2 and R papers; May/June 2019 through June 2026), paired there with their matching mark schemes. The archive lists only a small subset of examiner reports, so the guide does not claim that Pearson publishes a full-mark script for every exact question or prompt family.
