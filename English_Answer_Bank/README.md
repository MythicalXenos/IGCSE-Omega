# English Language B 4EB1 Answer Bank

Built 2026-10-12 from the Paperlords 4EB1 archive, the searchable text index, matching Pearson mark schemes, and official Pearson examiner reports.

## Deliverables

- `4EB1_Question_Type_Inventory.xlsx` — filterable five-sheet workbook with all 23 QP/MS pairs, 253 question-option entries (including all three Section C choices), extracted prompt text, marks, paper cover code and archive source paths, plus scored official candidate scripts.
- `4EB1_Exemplar_and_Model_Answer_Guide.docx` — main reading/coaching guide with reusable methods and clearly labelled constructed models.
- `4EB1_Exemplar_and_Model_Answer_Guide.md` — searchable source version.
- `Source_Notes/Official_Pearson_Exemplar_Index.md` — exact report score/page references and source URLs.
- `build_english_inventory.py` — rebuilds the workbook from the searchable index and QP/MS pairing CSV.
- `make_docx.py` — rebuilds the DOCX from the Markdown guide.

## Storage policy

No QP, Source Booklet, mark scheme or examiner-report PDFs were copied here. The archive retains the originals; the workbook points to their paths, and the guide links official Pearson reports. The searchable index remains in `Paperlords_Archive/Paperlords_Searchable_Text_Index.zip`.

## Evidence policy

- “OFFICIAL — full marks” means Pearson’s examiner report reproduces/reports a real candidate response and records all marks available for that exact question.
- Lower-scoring official responses are shown with their actual score and used for calibration.
- “CONSTRUCTED” means an original answer written from an exact past-paper question, source text and mark-scheme guidance. It is not a past-candidate script, is not an examiner-marked answer, and is not presented as perfect.
- The archive has two 4EB1 examiner reports (June 2023 P1 and P1R). Other report links in the source index are official online references and are not duplicated locally.
