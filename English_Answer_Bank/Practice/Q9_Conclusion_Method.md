# Building a Q9 conclusion without being given sentences

Three jobs, in this order:
1. Name what the essay proved - not what the topic is.
2. Say the proportion. How much of the statement survives? All / most / half / only for some.
3. Stop. No new idea, no second reversal, no summary marker.

Build order that keeps it from becoming a summary:
- Write job 2 first (the proportion). It is one clause.
- Then write the reason the essay gave for that proportion.
- Then cut everything else.

Test before moving on:
- Does it contain the prompt's key words, in your own sentence?
- Could this conclusion be attached to a different essay? If yes, it is a summary, not a landing.
- Does the final clause withdraw a claim the essay already made? If yes, delete it.
- Does it start with Overall / In conclusion / To sum up? Delete that word.
- Is there one sentence of six words or fewer?

Three legitimate endings, chosen by what the essay did:
- Verdict + reason. For when the evidence pointed one way.
- Boundary. For when the statement is true up to a limit, and you can name the limit.
- Reframe. For when the essay showed the statement was asking the wrong question.
