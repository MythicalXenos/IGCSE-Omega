# IGCSE-Omega

## Current focus: Pearson Edexcel International GCSE English Language B (4EB1)

The 4EB1 bank is in [`English_Answer_Bank/`](English_Answer_Bank/README.md). It inventories 23 QP/MS pairs and 253 question-option entries; that inventory is **not** a claim of 253 completed answers. Complete answer sets now cover June 2023 P1 and P1R, plus November 2023 P1 Section A Q1–Q7 (21/253); progress is tracked in [`Answer_Sets/README.md`](English_Answer_Bank/Answer_Sets/README.md). The bank also records selected constructed targets, official candidate-response score/page locators, facsimile-checked June 2023 transcript records for six candidate responses (including incomplete excerpts), and Section A examiner research; authentic scripts remain distinct from constructed models. The learner’s reported baseline is 50–55/100, with Section A (13–19/40) the immediate priority.
